CCIT102 Class Collaboration

Welcome to our GitHub Collaboration Activity!

Each student will:
1. Create their own branch.
2. Create their own file.
3. Commit their changes.
4. Push their branch.
5. Create a Pull Request.
6. Review another student's Pull Request.
7. Merge the Pull Request.
8. Pull the latest changes.

Important:
DO NOT push directly to main.
